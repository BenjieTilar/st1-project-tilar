# Benjie O. Tilar — Certificate & Badge Portfolio

A simple public portfolio website for certificates and digital badges.

## Add a certificate manually

1. Put the certificate/badge image inside `assets/`.
2. Open `script.js`.
3. Copy one credential object and change its title, issuer, date, tags, notes, link, and image path.
4. Example: `image: "assets/my-certificate.jpg"`
5. Commit/push the changes to GitHub.
6. Vercel will automatically redeploy the public website.

No database, Supabase, Firebase, or LocalStorage is required.
